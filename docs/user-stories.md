# 婚禮電子喜帖 User Stories

## Epic：三生三世沉浸式婚禮邀請

### US-001｜以故事開場

身為受邀賓客，
我希望進入頁面時先看到具有古風宣紙、墨暈與印章意象的水墨開場，
以便在正式閱讀婚禮資訊前，感受到「三生三世」的故事基調。

驗收條件：

- 開場使用繁體中文與古風視覺語彙。
- 向下滾動後，水墨自然散開並進入唐代場景。
- 向上滾動回到第一幕時，可以重新顯示水墨開場。

### US-002｜以滾動穿越四個時代

身為受邀賓客，
我希望每次滾動都能完整進入下一個時代場景，
以便感受到鏡頭穿越不同人生，而不是閱讀投影片。

驗收條件：

- 場景依序為：古代、近代、民國、今生。
- 一次滾動只切換一幕，不會連續跳過場景。
- 轉場過程不會停在半幕或突然跳出下一幕。
- 前後場景以連續淡化、深度推進與空間銜接完成轉場。
- 轉場期間不會露出矩形場景平面、方形圖片或影像殘留。

### US-003｜讓婚紗照成為每幕主軸

身為新人，
我希望每個時代的婚紗照都是視覺主角，
以便賓客能清楚理解照片與故事的關係。

驗收條件：

- 婚紗照不得被背景、文字或轉場效果壓過。
- 婚紗照尺寸適中，不得過小、過大或與文案重疊。
- 婚紗照邊緣使用自然羽化或空間融合，不顯示硬矩形邊界。
- 四個時代場景採一致的構圖邏輯：左側文案、右側婚紗照。
- 今生場景必須使用提供的今生婚紗照。
- 使用者提供的背景示意圖只作為建築風格參考，不得直接當作今生背景素材。

### US-004｜背景符合婚紗照視覺

身為新人，
我希望每幕背景的建築、色溫與空間語彙都能呼應婚紗照，
以便整體畫面自然且不違和。

驗收條件：

- 古代背景呼應至善園、古典庭園與唐代氛圍。
- 近代背景呼應歐風宮殿、階梯與古典建築。
- 民國背景呼應中式室內、木雕、屏風與暖色調。
- 今生背景依照提供的示意，使用奶油色牆面、雕花、古典家具與水晶燈等建築風格。
- 背景不得使用包含其他新人或人物的婚紗照作為環境背景。
- 背景素材應優先使用高解析原圖，並經適當壓縮以維持載入效能。

### US-005｜文字在任何背景上都清楚

身為受邀賓客，
我希望每幕的標題、故事文案與婚禮資訊都清楚可讀，
以便在不同明暗與複雜背景上仍能閱讀內容。

驗收條件：

- 左側文案與婚紗照不互相遮擋。
- 標題、眉標、正文與 HUD 具有足夠對比。
- 證婚與宴會資訊不得被背景吃掉。
- 場地連結具有明確邊框、色彩與可辨識的互動狀態。
- 桌面與手機版都不得裁切重要文字。

### US-006｜維持流暢與可及性

身為使用者，
我希望頁面在滾動、觸控與鍵盤操作時流暢且可預期，
以便在不同裝置上都能完成閱讀。

驗收條件：

- 場景動畫不因即時模糊或過量濾鏡造成卡頓。
- 大型背景素材使用 WebP 或等效最佳化格式。
- 滑鼠滾輪、觸控滑動、方向鍵與 PageUp/PageDown 都能操作。
- 支援 `prefers-reduced-motion`，降低動態效果後仍可閱讀全部內容。
- 每次重大視覺調整後，需使用瀏覽器逐幕截圖檢查。

### US-007｜婚禮資訊完整呈現

身為受邀賓客，
我希望能在邀請中清楚取得婚禮日期、時間與地點，
以便準時抵達並了解活動流程。

驗收條件：

- 日期：2026 / 10 / 04，星期日。
- 證婚儀式：8F 文華閣，09:50 開放入場、10:00 儀式開始、10:30–11:00 拍照。
- 結婚宴：B2 大宴會廳，12:00 開放入席、12:30 午宴開始。
- 顯示台北文華東方酒店名稱與場地連結。
- 場地資訊連結可開啟官方網站。

## QA 交付要求

- 使用 `agent-browser` 啟動本地專案。
- 逐幕檢查開場、四個時代、證婚與宴會場景。
- 至少檢查每幕穩定畫面，以及一至兩個轉場中點。
- 確認沒有矩形圖片邊界、畫面殘留、文字裁切、人物重疊或背景失焦。
- 通過 `npm run build` 與 `npm run lint` 後，才交由使用者確認。
