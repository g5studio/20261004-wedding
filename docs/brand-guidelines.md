# Brand Guidelines — 20261004 Wedding

## Identity

沈浸式婚禮電子喜帖：以滾動敘事帶領賓客走進婚禮當日的情緒與資訊。

## Voice

- 溫柔、克制、有儀式感
- 少字、多留白；一句話說完一個段落
- 避免行銷腔與表情符號

## Visual Identity

| Token role | Direction |
|---|---|
| Primary | 深苔綠（莊重、自然） |
| Secondary / Accent | 暖金褐（儀式、祝福） |
| Background | 霧白綠（空氣感，非奶油橘） |
| Foreground | 墨綠近黑（可讀性優先） |

## Typography

| Role | Font | Usage |
|---|---|---|
| Script | Great Vibes | 拉丁裝飾（&、Invitation） |
| Heading | Noto Serif TC | 中文標題、新人姓名 |
| Body | Noto Sans TC | 正文、資訊 |

## Page Pattern

依 `design-system/20261004-wedding/MASTER.md`：

1. Intro（垂直）
2. Journey（橫向敘事軌道）
3. Detail Reveal
4. Footer（垂直）

## Do / Don't

- Do：token 驅動顏色與間距；hero 全幅；尊重 `prefers-reduced-motion`
- Don't：卡片堆疊 hero、粉紫預設主題、emoji 當圖示
